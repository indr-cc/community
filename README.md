# indr.cc community

Share feedback and trainer compatibility reports for [indr.cc](https://indr.cc/). You can ride your own GPX tracks free forever.

- [Report your trainer experience](https://github.com/indr-cc/community/issues/new?template=trainer-report.yml)
- [Share feedback or report a problem](https://github.com/indr-cc/community/issues/new?template=feedback.yml)
- [See the trainer compatibility list](https://indr.cc/trainers/)

Reports are public GitHub issues. Maintainers review reports before updating the compatibility list; a report is not a guarantee for every firmware, browser, or operating system. A GitHub account is needed to submit. Do not post private ride files, locations, device identifiers, or other personal information.
